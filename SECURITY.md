# Security Policy

This repository contains course material: Jupyter notebooks, helper scripts,
Docker files and slides. It runs no hosted services and stores no user data.

## Reporting a vulnerability

If you find a security issue (for example a malicious link, an unsafe
dependency or a problem in the Docker setup), please report it privately with
GitHub's **Report a vulnerability** button on the repository's **Security**
tab. Please do not disclose it publicly before it has been fixed.

## Scope

- The notebooks, helper code and Docker files in this repository.
- The Python dependencies listed in `course_content/environment/requirements.txt`.
