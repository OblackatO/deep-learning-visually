# Contributing

Thank you for your interest in "Deep Learning, Visually".

This is a personal course project, and the additions in this repository are
not open source (see [`LICENSE`](LICENSE)). For that reason, pull requests are
not accepted at the moment.

You can still help:

- **Found a mistake, a broken link or a notebook that fails?** Open an issue
  with the notebook name, the cell, and the error message.
- **Have an idea for a better explanation or diagram?** Open an issue and
  describe it.

Issues that contain code or text you want included in the course should say
that you agree to it being used under the course's license.
